Remove plugin

Take the plugin out of ChannelFlow. You can also choose what happens to the data it stored — its database tables and saved settings.

  • Drop data — deletes the plugin's tables and its saved settings. Any information the plugin kept — transcoding overrides, change history, API keys — is permanently lost, and reinstalling starts from scratch.
  • Keep data — leaves the tables and settings in the database. They simply sit unused; reinstalling the plugin picks up where you left off.

    Transcode

    These are the instance defaults, and they mirror what ErsatzTV next reads to encode a stream. Every channel follows them until it saves its own overrides — a channel stores only the fields it changes, so editing a setting here reaches every channel that has not overridden that one field.

    Tasks

    Scheduled jobs like library scans and cache cleanup.

    Library scan

    Syncs the Jellyfin libraries you toggled on in the Library page. It runs daily on the server's clock, or on the crontab you give it instead.

    Maintenance

    One-off jobs you run yourself — these are not on a timer.

    Catalog cleanup

    Items removed from a media server are marked missing first. After the grace period the cleanup task deletes them. Manage removals from Library → Removed items.

    Weather

    Weather channels render a WeatherStar loop. Choose the look, the weather source, the default location, the units, and which screens play in the loop. The test resolves the location and reports the current forecast.

    Screens

    Emergency Broadcast System

    When NOAA has watches or warnings for the Weather tab location, programming splices an EBS graphic onto the current show — same show, same playhead, no Off Air slate. A ticker scrolls alert text over a pre-rendered strip; the alerts screen fills the frame and keeps the show audio lower under the attention/end tones. Choose the display and how often it cuts in, then test.

    CommercialBrainz

    Where ad avails come from and how picky the pool is. The server plus API token, the pool mode, how many results to sync, and the content filters. Test the connection before saving.
