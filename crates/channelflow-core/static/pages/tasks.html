Tasks

Scheduled jobs like library scans and cache cleanup.

Library scan

Syncs the Jellyfin libraries you toggled on in the Library page. It runs daily on the server's clock, or on the crontab you give it instead.

Past Tense News scan

Scans the Past Tense News event folders into the media database — it only touches the news connections, so it never waits on a slow media-server walk. Runs daily on the server's clock, or whenever you hit Run now.

FlowWire News video

Builds the newscast as an mp4 in /config/news at the configured hours (default 6, 10, 14, 18, 20, 22). The day's first build always runs so a video exists; later builds re-encode only when enough stories are new, otherwise the current video stays.

Run now behaves like a scheduled mark (respects the minimum-new-stories gate); Force rebuild always re-encodes, no matter how many stories are new. The build hours and the minimum live on the News page, alongside the feeds.

Local Files scan

Scans each Local Files connection's media folders into the database — one item per media file, with its .nfo metadata and poster. It only touches the local connections, so it never waits on a slow media-server walk. Runs daily on the server's clock, or whenever you hit Run now.

Maintenance

One-off jobs you run yourself — these are not on a timer.

Catalog cleanup

Items removed from a media server are marked missing first. After the grace period the cleanup task deletes them. Manage removals from Library → Removed items.
