Pair an app

On the ChannelFlow app, start pairing to get an 8-character PIN. Type it here and pair. ChannelFlow gives the app its own random API key, encrypts this instance's Live TV URLs (carrying that key) with the PIN, and hands the ciphertext to the relay, which forwards it to the waiting app — the relay never sees the key or the URLs, and this server never stores the PIN.

Relay:

Shown on the app while it waits; case and dashes do not matter.

What the app receives

The Live TV URLs for this instance (set them on General Settings). Pairing sends the local pair first when you are on the same network and the public pair otherwise, plus both variants so the app can fall back.
