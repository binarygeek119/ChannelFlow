Tasks

Scheduled jobs like library scans and cache cleanup.

Library scan

Syncs the Jellyfin libraries you toggled on in the Library page. It runs daily on the server's clock, or on the crontab you give it instead.

Maintenance

One-off jobs you run yourself — these are not on a timer.

Catalog cleanup

Items removed from a media server are marked missing first. After the grace period the cleanup task deletes them. Manage removals from Library → Removed items.
