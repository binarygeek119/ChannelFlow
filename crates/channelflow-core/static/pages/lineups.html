Lineups

A lineup is a channel's daily schedule — 48 half-hour slots per day, laid out the way it was in 1.0.0. Click a slot to give it weighted candidates; a long programme spans several blocks; the Week lineups row holds the days that do not run the default.

Default day

Click a 30-minute slot to edit candidates. A block can span several slots. Check Rerun to fill the slot from the previous day's primetime.
