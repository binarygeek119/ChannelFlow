Emergency Broadcast System

When NOAA has watches or warnings for the default Weather tab location, TV, movies, and music splice an EBS graphic onto the current program (same show, same playhead — no black screen or Off Air slate). Scrolling text overlays a pre-rendered copy of images/media/EBS/ebs_strip.png with WeatherStar 4000 text. Alerts screen fills the frame with a pre-rendered copy of images/media/EBS/ebs_fullscreen.png and keeps the show audio at a lower volume under the attention/end tones. Each alert dumps every live run-ahead buffer down to 60 seconds so it reaches the tuner faster, then the buffer fills back to the Transcode setting. WeatherStar and FlowWire keep their own displays.

Format

Target video and audio. Codec, profile, size, and frame rate follow the encoder on the Transcode card below.

Stream copy lets the ErsatzTV next engine hand HLS-compatible sources to the segmenter without re-encoding (H.264/HEVC/MPEG-2 video, AAC/AC-3/E-AC-3/MP2/MP3 audio). Everything else — and any item with a logo/bug overlay — still transcodes to the target below. Applies when ErsatzTV next is enabled; the built-in tuner engine always transcodes.

2.0 is stereo. 5.1, 7.1, and 7.2 upmix when the file has fewer speakers. Dolby Digital (AC-3) is 5.1 max; 7.1 and 7.2 encode as E-AC-3. Use 384 kbps or higher for surround.

Transcode

How FFmpeg encodes that format. The encoder name is chosen from the codec above plus this acceleration — there is no separate encoder list. Saved settings override FFMPEG_HWACCEL and FFMPEG_VAAPI_DEVICE without restarting the container. Intel Quick Sync (QSV) can hardware-decode AV1; VAAPI cannot on this Intel iHD path.

Pick a render node under /dev/dri (renderD128, renderD129, and any others the container can see). Intel Quick Sync is often D128; a second GPU may be D129 and still listed even if a probe says it cannot encode. Pass the whole /dev/dri folder into the container. QSV uses the same device as VAAPI, through oneVPL instead of libva decode.

Encoder: matching the Normalization codec to this acceleration.

Lets ffmpeg encode ahead of the tuner and hold that video so a hitch or commercial switch does not freeze the picture. New tuners also start from this buffer. 0 stays live (real time). 180–300 seconds (3–5 minutes) is the right size if the picture pauses. Maximum is 600 (10 minutes).

ErsatzTV next (transcoding)

ChannelFlow keeps scheduling, EPG, commercials, weather, news, and EBS, and delegates video encoding/streaming to the ErsatzTV next container. ChannelFlow writes its configuration into the appdata next folder (mount it into the container at /config/next) and pushes what to play to the engine over HTTP on every item boundary. The IPTV URLs stay the same — ChannelFlow proxies next's HLS behind them.

When enabled, the M3U handed to Jellyfin points at next's HLS (proxied through ChannelFlow) instead of ChannelFlow's own MPEG-TS encode. Old /iptv/stream URLs keep working as a fallback while the rest of your setup catches up.

How ChannelFlow reaches the next container's HTTP server (port 8409 by default).

How the next container reaches ChannelFlow to ask what is playing now. Use the same LAN address as the Local base URL above. Start the next container after saving; add or renumbering channels and changing normalization needs a next restart (restart the container once after saving).

Quick Pin

Open the ChannelFlow app and type the pin it shows. ChannelFlow encrypts the M3U and XMLTV links with that pin and sends only ciphertext to the pin server — both the public and local (same-network) URLs are included, and the app picks the local URLs when it is on your network. The app decrypts with the same pin.

Clients

Each ChannelFlow TV app gets its own API key when it pairs. Remove a client to destroy that key. The next time that TV tries to connect, it cannot, and it drops this server from its list.

After each library import, ChannelFlow reads chapter markers from local video files with ffprobe. At midnight it only scans videos that still have no chapter data. Run now to fill missing chapters without re-probing files that already have them.

True aspect ratio

At midnight ChannelFlow grabs 6 frames at five points in each video, compares the active picture inside the raster, and stores TrueAspectRatio. Playback uses that instead of the media-server aspect. Run now to measure videos that still have no TrueAspectRatio.

Story photos play during the newscast, her photo returns for the sign-off, then outro audio plays with the logo again.
